# DuMate 账号

## 添加账号

1. 打开 Mac 上的 DuMate，登录企业账号。
2. 打开 Modweft → 插件配置 → DuMate → 添加账号。
3. 点击“从本机 DuMate 添加”。程序会自动读取当前登录账号、验证登录状态并同步可用模型。

无需选择文件、寻找目录或运行命令。再次点击会更新同一个企业账号，不会重复添加。切换 DuMate
当前账号后再次点击，可以添加另一个账号。

未找到登录信息或会话过期时，先在 DuMate 中完成登录，再回来重试。

## 支持范围

- 需要 Modweft 1.1.2 或以上版本，支持当前 Mac 的 DuMate 公网企业账号。
- 当前已验证 `zhongzhi.dumate.cn` 企业租户与 `dumate-svc.baidu.com`
  官方网关；其他租户需要先在插件网络权限中明确授权。
- 个人版、私有化／VPC、企业自定义模型和非 OpenAI 协议模型暂不支持。
- 支持模型目录同步、文本／思考流、图片消息与工具调用协议转换。真实网关验证覆盖目录和文本／思考流，未逐模型验证图片及工具能力。
- 思考档位、快速通道和提示缓存路由参数未验证，调用时不发送。是否产生思考内容由上游模型决定。

## 实现边界

主程序只读 DuMate 固定位置的当前登录数据，解密后仅将匹配当前企业的会话交给插件校验，不修改 DuMate
的任何文件，不产生临时凭证文件，不将凭证返回界面。插件账号资源由宿主持久化，网关短期令牌由插件自动续取。

模型同步失败会保留已经添加的账号并提示原因。登录失效后，需在 DuMate 重新登录，再点击“从本机 DuMate
添加”更新账号。
